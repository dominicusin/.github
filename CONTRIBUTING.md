# Contributing

Thanks for your interest in contributing!

## How to contribute
1. Fork the repository and create a feature branch from `main`.
2. Keep changes focused; add tests where relevant.
3. Ensure CI is green (Dependabot auto-merge keeps deps current — rebase if needed).
4. Open a Pull Request with a clear description.

## Code style
- Python: `black` + `flake8` (see repo config)
- Haskell: `ormolu` / `fourmolu`, LiquidHaskell specs welcome
- Nix: `nixpkgs-fmt`

## Commits
Use conventional prefixes (`feat:`, `fix:`, `docs:`, `ci:`, `refactor:`).
